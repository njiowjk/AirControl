# AirControl

**AirControl** は、Macのカメラで手の動きを認識し、マウスを操作するPython製アプリケーションです。

MediaPipeで手の関節位置を検出し、ジェスチャーによってカーソル移動・左クリック・スクロールを行います。

> 現在開発中のプロジェクトです。操作精度やジェスチャーの認識には改善の余地があります。

## 主な機能

- 人差し指の動きによるカーソル移動
- 親指と中指をくっつけるジェスチャーによる左クリック
- 人差し指と中指を伸ばして上下に動かすスクロール操作（移動した位置で保持すると連続スクロール）
- カーソルの平滑化と、移動距離に応じた追従速度の調整
- カメラ映像への手の関節点・操作範囲の表示

## 操作方法

| 操作 | 方法 |
| --- | --- |
| カーソル移動 | 人差し指で指し示す |
| 左クリック | 中指を伸ばしてから親指と中指をくっつける |
| スクロール | 人差し指と中指を伸ばして上下に動かし、その位置で保持する |
| 操作 ON / OFF | カメラウィンドウで `m` キー |
| 終了 | カメラウィンドウで `q` キー |

## 動作環境

- macOS
- Python 3（MediaPipeに対応したバージョン）
- カメラ（内蔵カメラでも可）

## セットアップ

### 1. 仮想環境とライブラリ

リポジトリのフォルダで以下を実行します。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install mediapipe opencv-python pyautogui
```

### 2. 手の認識モデルを配置

```bash
mkdir -p models
curl -L "https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task" -o models/hand_landmarker.task
```

`main.py` は `models/hand_landmarker.task` を読み込むため、このパスにモデルファイルが必要です。

### 3. 実行

```bash
python main.py
```

初回起動時などに、macOSのカメラとアクセシビリティのアクセス許可が必要になる場合があります。

## 使用技術

- **Python** — アプリケーションの実装
- **OpenCV** — カメラ映像の取得・表示
- **MediaPipe** — 手の21個のランドマーク検出
- **PyAutoGUI** — マウスカーソル・クリック・スクロールの操作
